# Book Store Website

A modern and responsive online book store website developed using HTML, CSS, and JavaScript. This project allows users to explore books, search by category, view book details, and add books to the cart through an attractive and user-friendly interface.

## Features
- Responsive design
- Search bar for books
- Book categories
- Featured and trending books section
- Shopping cart UI
- Smooth animations and hover effects
- Modern user interface

## Technologies Used
- HTML
- CSS
- JavaScript

## Pages
- Home
- Books
- Categories
- Cart
- Contact

## Future Improvements
- User login/signup
- Online payment integration
- Wishlist feature
- Backend database support
- Book recommendation system
